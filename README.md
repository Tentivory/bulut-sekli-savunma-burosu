# Bulut Şekli Savunma Bürosu

> Gökyüzünde şekil görenler yalnız değildir. Artık avukatları vardır.

Bu depo, atmosferdeki su buharı kümelerinin toplumsal itibarını korumak için kurulmuş **resmi** (ama kimse resmileştirmemiş) bir bürodur.

## Neden var?

Çünkü birisi "o bulut koyuna benzemiyor" dediğinde koyunun avukatı yoktu. Artık var. Büro, müvekkil bulutun şeklini mahkeme üslubuyla savunur. Karar bağlayıcı değildir. Rüzgâr da değildir.

## Kurulum

```bash
python3 avukat.py "koçbaşı gibi duran kümülonimbus"
```

veya soru sorarak:

```bash
python3 avukat.py
```

## Yasal uyarı

- Bu yazılım gerçek bir mahkemede kullanılmaz.
- Kullanılırsa büro sorumluluk kabul etmez, çünkü büro aslında bir `.py` dosyasıdır.
- Bulutlar tüzel kişilik talep ederse lütfen issue açın.
